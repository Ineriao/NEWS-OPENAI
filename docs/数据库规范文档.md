# 数据库规范文档

## 一、数据库概述

### 1.1 基本信息

| 属性 | 值 |
|------|------|
| 数据库名 | news_system |
| 字符集 | utf8mb4 |
| 排序规则 | utf8mb4_unicode_ci |
| 引擎 | InnoDB |
| MySQL 版本 | 8.0+ |

### 1.2 为什么使用 utf8mb4？

- utf8mb4 是 MySQL 中真正的 UTF-8 编码
- 支持 emoji 表情符号（4字节字符）
- utf8 只支持最多 3 字节的字符

## 二、表结构设计

### 2.1 用户表 (user)

**用途**：存储系统用户信息

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| id | BIGINT | PK, AUTO_INCREMENT | 主键 |
| username | VARCHAR(50) | NOT NULL, UNIQUE | 用户名 |
| password | VARCHAR(255) | NOT NULL | BCrypt 加密密码 |
| email | VARCHAR(100) | | 邮箱 |
| avatar | VARCHAR(255) | | 头像 URL |
| role | TINYINT | NOT NULL, DEFAULT 1 | 角色 |
| status | TINYINT | NOT NULL, DEFAULT 1 | 状态 |
| create_time | DATETIME | DEFAULT CURRENT_TIMESTAMP | 创建时间 |
| update_time | DATETIME | ON UPDATE CURRENT_TIMESTAMP | 更新时间 |

**角色说明**：
| 值 | 角色 | 权限 |
|----|------|------|
| 1 | 普通用户 | 浏览、评论 |
| 2 | 编辑 | 撰写、编辑新闻 |
| 3 | 总编 | 审核、发布新闻 |
| 4 | 管理员 | 系统管理 |

---

### 2.2 新闻分类表 (category)

**用途**：存储新闻分类，支持二级分类

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| id | BIGINT | PK, AUTO_INCREMENT | 主键 |
| name | VARCHAR(50) | NOT NULL | 分类名称 |
| parent_id | BIGINT | FK → category(id) | 父分类ID |
| sort_order | INT | DEFAULT 0 | 排序顺序 |
| create_time | DATETIME | DEFAULT CURRENT_TIMESTAMP | 创建时间 |

**树形结构示例**：
```
时政新闻 (parent_id=NULL)
├── 国内时政 (parent_id=1)
└── 国际时政 (parent_id=1)
```

---

### 2.3 新闻表 (news)

**用途**：存储新闻内容及其状态

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| id | BIGINT | PK, AUTO_INCREMENT | 主键 |
| title | VARCHAR(200) | NOT NULL | 标题 |
| summary | VARCHAR(500) | | 摘要 |
| content | LONGTEXT | | 内容（富文本） |
| cover_image | VARCHAR(255) | | 封面图片 |
| category_id | BIGINT | FK → category(id) | 分类ID |
| author_id | BIGINT | FK → user(id) | 作者ID |
| reviewer_id | BIGINT | FK → user(id) | 审核人ID |
| status | TINYINT | DEFAULT 0 | 状态 |
| view_count | INT | DEFAULT 0 | 浏览次数 |
| like_count | INT | DEFAULT 0 | 点赞数 [2024-12-15 新增] |
| collection_count | INT | DEFAULT 0 | 收藏数 [2024-12-15 新增] |
| publish_time | DATETIME | | 发布时间 |
| create_time | DATETIME | DEFAULT CURRENT_TIMESTAMP | 创建时间 |
| update_time | DATETIME | ON UPDATE CURRENT_TIMESTAMP | 更新时间 |

**状态流转**：
```
草稿(0) → 待审核(1) → 已发布(2) → 已存档(3)
   ↑          │
   └──────────┘ (退回修改)
```

---

### 2.4 评论表 (comment)

**用途**：存储用户评论，支持回复

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| id | BIGINT | PK, AUTO_INCREMENT | 主键 |
| news_id | BIGINT | FK → news(id), ON DELETE CASCADE | 新闻ID |
| user_id | BIGINT | FK → user(id) | 用户ID |
| content | TEXT | NOT NULL | 评论内容 |
| parent_id | BIGINT | FK → comment(id) | 父评论ID（回复） |
| status | TINYINT | DEFAULT 1 | 状态：0-隐藏, 1-显示 |
| create_time | DATETIME | DEFAULT CURRENT_TIMESTAMP | 创建时间 |

**级联删除**：删除新闻时自动删除所有评论

---

### 2.5 热搜表 (hot_search)

**用途**：存储各平台热搜数据，保留历史记录

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| id | BIGINT | PK, AUTO_INCREMENT | 主键 |
| title | VARCHAR(255) | NOT NULL | 热搜标题 |
| hot | VARCHAR(50) | | 热度值 |
| url | VARCHAR(500) | | 链接地址 |
| source | VARCHAR(20) | NOT NULL | 来源平台 |
| rank_num | INT | NOT NULL | 排名（1-10） |
| fetch_time | DATETIME | DEFAULT CURRENT_TIMESTAMP | 抓取时间 |

**来源平台**：微博、抖音、知乎、百度

**数据策略**：
- 每次刷新保存前10条
- 保留历史记录，支持趋势分析

---

### 2.6 外部新闻表 (external_news)

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| id | BIGINT | PK, AUTO_INCREMENT | 主键 |
| title | VARCHAR(255) | NOT NULL | 新闻标题 |
| description | TEXT | | 新闻摘要 |
| url | VARCHAR(500) | | 原文链接 |
| cover_image | VARCHAR(500) | | 封面图片 |
| source | VARCHAR(50) | NOT NULL | 来源平台 |
| hot | VARCHAR(50) | | 热度值 |
| fetch_time | DATETIME | DEFAULT CURRENT_TIMESTAMP | 抓取时间 |

**来源平台**：36氪、IT之家、澎湃新闻、今日头条

**数据策略**：
- 每次刷新保存前10条

---

### 2.7 新闻点赞表 (news_like) [2024-12-15 新增]

**用途**：存储用户对新闻的点赞记录

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| id | BIGINT | PK, AUTO_INCREMENT | 主键 |

- `idx_user_id (user_id)` - 用户点赞查询

## 三、ER 关系图

```
┌──────────┐
│   user   │
└────┬─────┘
     │ 1:N
     ├─────────────────┐
     │                 │
     ▼                 ▼
┌──────────┐     ┌──────────┐
│   news   │◄────│ comment  │
└────┬─────┘     └──────────┘
     │                 │
     │ N:1             │ 自引用
     ▼                 │
┌──────────┐           │
│ category │◄──────────┘
└──────────┘
     │
     │ 自引用（二级分类）
     ▼

独立表（无外键关联）：
┌──────────────┐     ┌─────────────────┐
│  hot_search  │     │  external_news  │
└──────────────┘     └─────────────────┘
```

**关系说明**：
| 关系 | 说明 |
|------|------|
| user 1:N news | 用户可发布多条新闻（作者） |
| user 1:N news | 用户可审核多条新闻（审核人） |
| user 1:N comment | 用户可发表多条评论 |
| category 1:N news | 分类下有多条新闻 |
| news 1:N comment | 新闻下有多条评论 |
| category 自引用 | 支持二级分类 |
| comment 自引用 | 支持评论回复 |

## 五、命名规范

### 表命名
- 小写字母 + 下划线
- 单数形式（user 而非 users）

### 字段命名
| 类型 | 规则 | 示例 |
|------|------|------|
| 主键 | id | id |
| 外键 | 关联表名_id | category_id, user_id |
| 时间 | xxx_time | create_time, fetch_time |
| 状态 | status | status |
| 数量 | xxx_count | view_count |

### 索引命名
| 类型 | 规则 | 示例 |
|------|------|------|
| 普通索引 | idx_字段名 | idx_status |
| 唯一索引 | uk_字段名 | uk_username |
| 复合索引 | idx_字段1_字段2 | idx_source_time |

## 六、数据类型选择

| 场景 | 类型 | 说明 |
|------|------|------|
| 主键 | BIGINT | 支持大数据量，8字节 |

| 富文本 | LONGTEXT | 新闻正文（4GB） |

## 八、常用 SQL

### 查询已发布新闻（分页）
```sql
SELECT n.*, c.name AS category_name, u.username AS author_name
FROM news n
LEFT JOIN category c ON n.category_id = c.id
LEFT JOIN user u ON n.author_id = u.id
WHERE n.status = 2
ORDER BY n.publish_time DESC
LIMIT 0, 10;
```

### 查询最新热搜（按平台）
```sql
SELECT * FROM hot_search
WHERE source = '微博'
ORDER BY fetch_time DESC, rank_num ASC
LIMIT 10;
```

### 查询最新外部新闻
```sql
SELECT * FROM external_news
ORDER BY fetch_time DESC
LIMIT 20;
```

### 统计各状态新闻数量
```sql
SELECT status, COUNT(*) AS count
FROM news
GROUP BY status;
```
