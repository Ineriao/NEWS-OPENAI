# 开发问题记录

## 1. JDK 21.0.6 与 Lombok 不兼容问题

### 问题描述
使用 JDK 21.0.6 编译项目时，Lombok 注解处理器报错：

```
java.lang.ExceptionInInitializerError: com.sun.tools.javac.code.TypeTag :: UNKNOWN
Caused by: java.lang.NoSuchFieldException: com.sun.tools.javac.code.TypeTag :: UNKNOWN
```

### 原因分析
JDK 21.0.6 是较新的补丁版本，其内部 API `com.sun.tools.javac.code.TypeTag` 发生了变化，移除或重命名了 `UNKNOWN` 字段。Lombok 依赖这些内部 API 来生成代码，因此无法正常工作。

### 尝试的解决方案

1. **升级 Lombok 版本**
   - 尝试 1.18.34、1.18.36 版本
   - 结果：无效，问题依旧

2. **添加 JVM 参数**
   ```
   --add-opens=jdk.compiler/com.sun.tools.javac.code=ALL-UNNAMED
   --add-opens=jdk.compiler/com.sun.tools.javac.comp=ALL-UNNAMED
   ```
   - 结果：无效，问题依旧

3. **使用 Eclipse 编译器 (ECJ)**
   - 配置 plexus-compiler-eclipse
   - 结果：配置复杂，出现其他错误

### 最终解决方案
**降级 JDK 版本**，推荐使用：
- **JDK 17**（最稳定的 LTS 版本）
- **JDK 21.0.3 或更早版本**

### pom.xml 配置

```xml
<properties>
    <java.version>17</java.version>
</properties>

<plugin>
    <groupId>org.apache.maven.plugins</groupId>
    <artifactId>maven-compiler-plugin</artifactId>
    <version>3.11.0</version>
    <configuration>
        <source>17</source>
        <target>17</target>
        <annotationProcessorPaths>
            <path>
                <groupId>org.projectlombok</groupId>
                <artifactId>lombok</artifactId>
                <version>1.18.30</version>
            </path>
        </annotationProcessorPaths>
    </configuration>
</plugin>
```

- [Lombok GitHub Issues](https://github.com/projectlombok/lombok/issues)
- [JDK 21 Release Notes](https://www.oracle.com/java/technologies/javase/21-relnotes.html)

## 2. DailyHotApi 部署注意事项

### 问题：启动失败，找不到 dist/index.js

**原因**：未执行构建命令

**解决方案**：
```bash
npm run build  # 先构建
npm run start  # 再启动
```

### 问题：API 响应格式差异

**原因**：DailyHotApi 与原 vvhan API 响应格式不同

**差异对比**：

| 字段 | vvhan API | DailyHotApi |
|------|-----------|-------------|
| 成功标识 | `success: true` | `code: 200` |
| 数据字段 | `data` | `data` |
| 热度字段 | `hot` | `hot`（部分平台可能没有） |

**解决方案**：修改 `HotSearchServiceImpl.java` 中的解析逻辑

## 3. JDK 17 安装与配置

### 问题：需要使用 JDK 17 替代 JDK 21.0.6

由于 JDK 21.0.6 与 Lombok 不兼容，需要安装 JDK 17。

### 安装方法

**方法一：使用 winget（推荐）**
```bash
winget install Microsoft.OpenJDK.17
```
安装完成后，JDK 默认位于：`C:\Program Files\Microsoft\jdk-17.x.x.x`

**方法二：手动下载**
- 下载地址：https://adoptium.net/temurin/releases/
- 选择 JDK 17 LTS 版本

### 配置步骤

1. **复制 JDK 到指定目录**（可选）
```bash
xcopy "C:\Program Files\Microsoft\jdk-17.0.17.8-hotspot" "D:\jdk17" /E /I /H
```

2. **编译项目时指定 JDK**
```bash
set JAVA_HOME=D:\jdk17
mvn clean package -DskipTests
```

3. **运行项目**
```bash
D:\jdk17\bin\java.exe -jar target\news-backend-1.0.0.jar
```

## 4. MySQL 数据库表创建

### 问题：hot_search 表不存在

**错误信息**：
```
java.sql.SQLSyntaxErrorException: Table 'news_system.hot_search' doesn't exist
```

**解决方案**：在 MySQL 中执行建表语句
```sql
CREATE TABLE IF NOT EXISTS `hot_search` (
    `id` BIGINT PRIMARY KEY AUTO_INCREMENT COMMENT '热搜ID',
    `title` VARCHAR(255) NOT NULL COMMENT '热搜标题',
    `hot` VARCHAR(50) COMMENT '热度值',
    `url` VARCHAR(500) COMMENT '链接地址',
    `source` VARCHAR(20) NOT NULL COMMENT '来源平台',
    `rank_num` INT NOT NULL COMMENT '排名',
    `fetch_time` DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '抓取时间',
    INDEX `idx_source` (`source`),
    INDEX `idx_fetch_time` (`fetch_time`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='热搜表';
```

## 5. 端口占用问题

### 问题：Port 8080 is already in use

**解决方案**：

1. 查找占用端口的进程：
```bash
netstat -ano | findstr :8080
```

2. 终止进程（PowerShell）：
```powershell
Stop-Process -Id <PID> -Force
```

## 8. 数据库管理工具说明

### 问题：数据库中出现 "New Group" 文件夹

**原因**：这是数据库管理工具（如 Navicat、DBeaver、DataGrip 等）的 UI 分组功能，用于组织表的显示，不是实际的数据库对象。

**处理方式**：可以右键删除该分组，不会影响任何数据。

### 问题：comment 和 external_news 表为空

**原因**：这是正常现象，这两个表需要用户操作或调用接口才会有数据：

| 表名 | 数据来源 |
|------|----------|
| comment | 用户在新闻详情页发表评论 |
| external_news | 调用 `/api/public/external-news/refresh` 接口抓取数据 |

**说明**：初始状态为空表是正常的，不影响系统功能。

## 9. 点赞和收藏功能 [2024-12-15 新增]

### 功能说明

| 功能 | 接口 | 说明 |
|------|------|------|
| 点赞/取消点赞 | POST `/api/news/{newsId}/like` | 需要登录，toggle 机制 |
| 获取点赞状态 | GET `/api/public/news/{newsId}/like` | 公开接口 |
| 收藏/取消收藏 | POST `/api/news/{newsId}/collect` | 需要登录，toggle 机制 |
| 获取收藏状态 | GET `/api/public/news/{newsId}/collect` | 公开接口 |
| 获取收藏列表 | GET `/api/user/collections` | 需要登录，分页返回 |

### 新增数据库表

| 表名 | 说明 |
|------|------|
| news_like | 点赞记录表（唯一约束：news_id + user_id） |
| news_collection | 收藏记录表（唯一约束：news_id + user_id） |

### 新增字段（news 表）

| 字段 | 类型 | 说明 |
|------|------|------|
| like_count | INT | 点赞数 |
| collection_count | INT | 收藏数 |

### 前端交互

- 点赞按钮：点击后变紫色高亮
- 收藏按钮：点击后变橙色高亮（星星图标）
- 未登录点击提示"请先登录"
