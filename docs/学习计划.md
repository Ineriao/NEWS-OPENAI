#### 2. 事务管理
```java
@Service
public class CommentServiceImpl implements CommentService {

    @Transactional  // 开启事务，异常自动回滚
    public void deleteComment(Long id, Long operatorId, Integer role) {
        // 1. 查询评论
        Comment comment = commentMapper.selectById(id);
        // 2. 权限校验
        if (!comment.getUserId().equals(operatorId) && role < 4) {
            throw new RuntimeException("无权删除");  // 抛异常会回滚
        }
        // 3. 软删除
        comment.setStatus(0);
        commentMapper.updateById(comment);
    }
}
```

#### 3. 业务逻辑示例（评论树构建）
```java
// CommentServiceImpl.java - 经典的树形结构构建
public List<CommentVO> getCommentsByNewsId(Long newsId) {
    // 1. 一次性查询所有评论（避免 N+1 问题）
    List<Comment> allComments = commentMapper.selectAllByNewsId(newsId);

    // 2. 构建 ID -> 评论 的映射
    Map<Long, Comment> commentMap = new HashMap<>();
    for (Comment c : allComments) {
        commentMap.put(c.getId(), c);
    }

    // 3. 分离一级评论和回复
    List<Comment> topComments = new ArrayList<>();
    for (Comment c : allComments) {
        if (c.getParentId() == null) {
            topComments.add(c);  // 一级评论
        } else {
            Comment parent = commentMap.get(c.getParentId());
            parent.getReplies().add(c);  // 添加到父评论的回复列表
        }
    }

    return topComments.stream().map(CommentVO::fromComment).collect(...);
}
```

### 核心知识点

#### 1. JWT 结构
```
eyJhbGciOiJIUzI1NiJ9.eyJ1c2VySWQiOjEsInVzZXJuYW1lIjoiYWRtaW4ifQ.xxxxx
|_____Header_____|._________Payload_________|._Signature_|

Header: {"alg": "HS256"}           - 算法
Payload: {"userId": 1, "role": 4}  - 用户信息
Signature: HMAC(header + payload, secret)  - 签名
```

#### 2. Token 生成与解析
```java
// JwtUtil.java
public class JwtUtil {
    private static final String SECRET = "your-secret-key";
    private static final long EXPIRE = 24 * 60 * 60 * 1000;  // 24小时

    // 生成 Token
    public static String generateToken(User user) {
        return Jwts.builder()
                .setSubject(user.getUsername())
                .claim("userId", user.getId())
                .claim("role", user.getRole())
                .setIssuedAt(new Date())
                .setExpiration(new Date(System.currentTimeMillis() + EXPIRE))
                .signWith(SignatureAlgorithm.HS256, SECRET)
                .compact();
    }

    // 解析 Token
    public static Claims parseToken(String token) {
        return Jwts.parser()
                .setSigningKey(SECRET)
                .parseClaimsJws(token)
                .getBody();
    }
}
```

#### 3. 拦截器实现
```java
// JwtInterceptor.java
@Component
public class JwtInterceptor implements HandlerInterceptor {

    @Override
    public boolean preHandle(HttpServletRequest request,
                            HttpServletResponse response,
                            Object handler) {
        // 1. 获取 Token
        String token = request.getHeader("Authorization");

        // 2. 公开接口放行
        String uri = request.getRequestURI();
        if (uri.startsWith("/api/public/") || uri.startsWith("/api/auth/")) {
            return true;
        }

        // 3. 验证 Token
        if (token == null || token.isEmpty()) {
            response.setStatus(401);
            return false;
        }

        try {
            Claims claims = JwtUtil.parseToken(token);
            // 4. 将用户信息存入 request，供 Controller 使用
            request.setAttribute("userId", claims.get("userId", Long.class));
            request.setAttribute("role", claims.get("role", Integer.class));
            return true;
        } catch (Exception e) {
            response.setStatus(401);
            return false;
        }
    }
}
```

#### 4. 注册拦截器
```java
// WebConfig.java
@Configuration
public class WebConfig implements WebMvcConfigurer {

    @Autowired
    private JwtInterceptor jwtInterceptor;

    @Override
    public void addInterceptors(InterceptorRegistry registry) {
        registry.addInterceptor(jwtInterceptor)
                .addPathPatterns("/api/**")           // 拦截所有 /api 请求
                .excludePathPatterns(                  // 排除公开接口
                    "/api/auth/**",
                    "/api/public/**"
                );
    }
}
```

### 核心知识点

#### 1. 缓存注解
```java
@Service
public class CategoryServiceImpl implements CategoryService {

    // 添加缓存：方法返回值会被缓存
    @Cacheable(value = "category", key = "'tree'")
    public List<Category> getTreeList() {
        // 首次调用：执行方法，结果存入缓存
        // 再次调用：直接返回缓存，不执行方法
        return categoryMapper.selectList(null);
    }

    // 清除缓存：方法执行后清除指定缓存
    @CacheEvict(value = "category", allEntries = true)
    public void create(CategoryDTO dto) {
        categoryMapper.insert(...);
        // 新增分类后，清除所有分类缓存
    }
}
```

## 常见问题

### Q: 启动报错 "端口被占用"
```bash
# Windows
netstat -ano | findstr :8080
taskkill /F /PID <PID>

# 或者修改 application.yml 的 server.port
```

### Q: 数据库连接失败
1. 检查 MySQL 是否启动
2. 检查 application.yml 中的数据库配置
3. 检查用户名密码是否正确

### Q: Redis/ES 连接失败
本项目已配置降级策略，不影响核心功能：
- Redis 不可用 → 无缓存模式
- ES 不可用 → MySQL LIKE 搜索

### Q: 编译报错 "Lombok 不兼容"
确保使用 JDK 17（不是 21+），运行 `build.bat` 会自动切换
