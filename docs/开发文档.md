# 新闻发布管理系统 - 开发文档

## 一、项目概述

新闻发布管理系统是一个模拟新闻媒介发布流程的 Web 应用，支持多角色权限管理。

### 核心功能模块
1. **登录/注册模块** - 游客访问、普通用户登录、后台登录
2. **前台信息浏览** - 首页展示、栏目页面、新闻详情、搜索、评论
3. **新闻编辑管理** - 分类管理、新闻增删改查
4. **新闻总编管理** - 新闻审核、发布、修改、存档
5. **信息管理** - 用户/编辑/总编/新闻/评论管理
6. **热搜展示** - 多平台热搜聚合、历史记录查询
7. **外部新闻** - 从多个新闻源获取并展示新闻

## 四、数据库设计

### 数据表概览
| 表名 | 说明 |
|------|------|
| user | 用户表（角色：1=普通用户, 2=编辑, 3=总编, 4=管理员） |
| category | 分类表（支持二级分类） |
| news | 新闻表（状态：0=草稿, 1=待审核, 2=已发布, 3=已存档） |
| comment | 评论表（支持回复） |
| hot_search | 热搜表（保存前10条，保留历史记录） |
| external_news | 外部新闻表（从 API 抓取的新闻） |
| news_like | 点赞表（用户-新闻点赞关系）[2024-12-15 新增] |
| news_collection | 收藏表（用户-新闻收藏关系）[2024-12-15 新增] |
| comment_like | 评论点赞表（用户-评论点赞关系）[2024-12-15 新增] |

### 定时任务 [2024-12-15 新增]
| 任务 | 周期 | 说明 |
|------|------|------|
| 热搜刷新 | 每30分钟 | 自动刷新微博/抖音/知乎/百度热搜 |
| 外部新闻刷新 | 每小时 | 自动刷新36氪/IT之家/澎湃/头条新闻 |
| 初始刷新 | 启动后10秒 | 应用启动时自动执行一次刷新 |

**上传接口返回格式：**
```json
// 通用上传
{
  "code": 200,
  "data": {
    "url": "/uploads/2025/12/15/img_xxx.jpg",
    "filename": "xxx.jpg"
  }
}

// 编辑器上传（WangedEditor 规范）
{
  "errno": 0,
  "data": {
    "url": "/uploads/2025/12/15/editor_xxx.jpg"
  }
}
```

**文件存储结构：**
```
D:/uploads/news/
├── 2025/
│   └── 12/
│       └── 15/
│           ├── img_xxxx.jpg      # 头像/封面
│           └── editor_xxxx.png   # 编辑器图片
```
