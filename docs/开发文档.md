# 新闻发布管理系统 - 开发文档

## 一、项目概述

新闻发布管理系统是一个模拟新闻媒介发布流程的 Web 应用，支持多角色权限管理。

### 核心功能模块
1. **登录/注册模块** - 游客访问、普通用户登录、后台登录
2. **前台信息浏览** - 首页展示、栏目页面、新闻详情、搜索、评论
3. **新闻编辑管理** - 分类管理、新闻增删改查
4. **新闻总编管理** - 新闻审核、发布、修改、存档
5. **信息管理** - 用户/编辑/总编/新闻/评论管理
6. **热搜展示** - 多平台热搜聚合、历史记录查询
7. **外部新闻** - 从多个新闻源获取并展示新闻

## 四、数据库设计

### 数据表概览
| 表名 | 说明 |
|------|------|
| user | 用户表（角色：1=普通用户, 2=编辑, 3=总编, 4=管理员） |
| category | 分类表（支持二级分类） |
| news | 新闻表（状态：0=草稿, 1=待审核, 2=已发布, 3=已存档） |
| comment | 评论表（支持回复） |
| hot_search | 热搜表（保存前10条，保留历史记录） |
| external_news | 外部新闻表（从 API 抓取的新闻） |
| news_like | 点赞表（用户-新闻点赞关系）[2024-12-15 新增] |
| news_collection | 收藏表（用户-新闻收藏关系）[2024-12-15 新增] |

## 五、API 接口

### 认证接口
| 方法 | 路径 | 说明 |
|------|------|------|
| POST | /api/auth/register | 用户注册 |
| POST | /api/auth/login | 用户登录 |
| GET | /api/auth/info | 获取当前用户信息 |

### 分类接口
| 方法 | 路径 | 说明 |
|------|------|------|
| GET | /api/public/categories | 获取分类树 |
| GET | /api/public/categories/detail/{id} | 获取单个分类详情 |

### 新闻接口
| 方法 | 路径 | 说明 |
|------|------|------|
| GET | /api/public/news | 获取已发布新闻列表 |
| GET | /api/public/news/{id} | 获取新闻详情 |
| POST | /api/news | 创建新闻（编辑权限） |
| PUT | /api/news/{id} | 更新新闻 |
| PUT | /api/news/{id}/submit | 提交审核 |
| PUT | /api/news/{id}/approve | 审核通过（总编权限） |
| PUT | /api/news/{id}/reject | 退回修改（总编权限） |

### 热搜接口
| 方法 | 路径 | 说明 |
|------|------|------|
| GET | /api/public/hot/{platform} | 获取指定平台热搜 |
| POST | /api/public/hot/refresh | 刷新并保存热搜（前10条） |
| GET | /api/public/hot/db/{source} | 从数据库获取最新热搜 |
| GET | /api/public/hot/history/{source} | 获取历史热搜记录 |

### 外部新闻接口
| 方法 | 路径 | 说明 |
|------|------|------|
| GET | /api/public/external-news/{platform} | 获取指定平台新闻 |
| POST | /api/public/external-news/refresh | 刷新并保存新闻（前10条） |
| GET | /api/public/external-news/latest | 获取最新新闻（首页展示） |

### 点赞接口 [2024-12-15 新增]
| 方法 | 路径 | 说明 |
|------|------|------|
| POST | /api/news/{newsId}/like | 点赞/取消点赞（需登录） |
| GET | /api/public/news/{newsId}/like | 获取点赞状态和数量 |

### 收藏接口 [2024-12-15 新增]
| 方法 | 路径 | 说明 |
|------|------|------|
| POST | /api/news/{newsId}/collect | 收藏/取消收藏（需登录） |
| GET | /api/public/news/{newsId}/collect | 获取收藏状态和数量 |
| GET | /api/user/collections | 获取用户收藏列表（分页） |

### 技术亮点

1. **前后端分离**：Vue 3 + Spring Boot，通过 RESTful API 通信
2. **JWT 认证**：无状态认证，支持分布式部署
3. **MyBatis-Plus**：简化数据库操作，Lambda 条件构造
4. **状态机模式**：新闻审核流程清晰可控
5. **树形结构**：分类和评论支持层级关系
6. **外部数据集成**：热搜和新闻聚合展示
7. **深色模式**：CSS 变量 + Pinia 状态管理，支持系统偏好跟随 [2024-12-15 新增]
